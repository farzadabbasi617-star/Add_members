## دامنهٔ پروژه

این ربات **سه کار** انجام می‌دهد و بس:

| بخش | توضیح |
|---|---|
| 🎯 **استخراج** | ۱۲ متد اسکرپ ممبر از گروه/کانال — تک‌اکانتی و موازی |
| ➕ **ادد ممبر** | تک‌اکانتی و موازی، با دو حالت سرعت و موتور ضدبن مشترک |
| 🛡️ **محافظت گروه** | ضدلینک، ضداسپم، ضدفحش، ضدفلاد، کپچا، مدیریت اعضا |

هر چیز دیگری عمداً بیرون است. نسخهٔ قبلی این ربات ماژول‌های اینستاگرام،
گنج‌یاب، اکانت‌یاب، گروه‌یاب، دسته‌بندی هوشمند و اسکن خودکار را هم داشت؛
همگی حذف شدند چون منو را شلوغ می‌کردند بدون اینکه به کار اصلی کمکی کنند.

## دو حالت سرعت

نسخهٔ قبلی چهار حالت داشت (`max` / `ultra` / `fast` / `safe`) که تفاوتشان
برای کاربر روشن نبود. حالا دو حالت است:

| حالت | تأخیر بین هر ادد | استراحت | برای چه کسی |
|---|---|---|---|
| 🐌 **آهسته و امن** | ۶۰–۱۴۰ ثانیه | ۴–۱۰ دقیقه | اکانت نو، یا وقتی مکرر PEER_FLOOD می‌گیری |
| ⚡ **اولترا فست** | ۸–۱۸ ثانیه | ۱–۲.۵ دقیقه | اکانت قدیمی و گرم |

> ⚠️ تأخیر «هر اکانت» است، نه هر گروه. با ۶ اکانت موازی، فاصلهٔ مؤثر روی
> گروه مقصد شش برابر کمتر می‌شود. موتور این را در محاسباتش لحاظ می‌کند.

## ادد تک‌اکانتی = ادد موازی

هر دو از **یک موتور** استفاده می‌کنند: همان تأخیر انسانی، همان لیست
«هرگز دوباره ادد نشود»، همان محافظ ضدبن، همان گزارش زنده. تک‌اکانتی صرفاً
حالتی از موازی با یک ورکر است — نه یک مسیر جداگانه با کیفیت پایین‌تر.

## معماری

```
bot.py             ← ورودی اصلی، منوها، هندلرها
callback_router.py ← جدول اعزام کال‌بک (تطبیق دقیق > پیشوندی)
step_router.py     ← جدول اعزام مراحل گفت‌وگو، با پشتیبانی از گارد
add_queue.py       ← ترتیب‌دهی صف ادد (خالص و تست‌شده)
add_engine.py      ← تأخیر انسانی، لیست ممنوعه، محاسبهٔ مقصد
attacker.py        ← ۱۲ متد اسکرپ
parallel.py        ← ادد موازی چند اکانتی
defender.py        ← محافظت گروه (کپچا / هانی‌پات)
group_manager.py   ← ban/mute/warn، ضدلینک، ضداسپم، ضدفحش
account_doctor.py  ← تشخیص سلامت اکانت‌ها
account_login.py   ← فرآیند لاگین
account_state.py   ← قفل «اکانت مشغول» با TTL
session_store.py   ← نگهداری سشن روی دیسک + بکاپ در دیتابیس
db.py              ← PostgreSQL، پول اتصال، رمزنگاری سشن
web_app.py         ← مینی‌اپ تلگرام + REST API
config.py          ← پیکربندی مرکزی
tests/             ← ۴۴۲ تست + CI گیت‌هاب
```

## راه‌اندازی

```bash
pip install -r requirements.txt
python bot.py
```

### متغیرهای الزامی

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | از [@BotFather](https://t.me/BotFather) |
| `API_ID` / `API_HASH` | از [my.telegram.org](https://my.telegram.org) |
| `ADMIN_ID` | آیدی عددی تلگرام شما |
| `DATABASE_URL` | رشتهٔ اتصال PostgreSQL |
| `SESSION_ENCRYPTION_KEY` | کلید رمزنگاری سشن‌ها |

> جدول‌ها خودکار ساخته می‌شوند (`CREATE TABLE IF NOT EXISTS`)، پس دیتابیس
> خالی کافی است.

## تست

python -m pytest tests/
